3. Приклади запуску командЗапуск утиліти здійснюється з кореня репозиторію через модуль python -m.   Запуск демонстрації Завдання 1 (Моделі ООП):

Запуск аналізатора логів Завдання 2:
Ця команда запускає парсинг файлу access.log із фактичними назвами файлів та зберігає звіт:
python -m labs.lab02.main analyze --log-file labs/lab02/data/data_v01/access.log --output labs/lab02/data/data_v01/web_analysis_report.json --min-status 400 --top 5 --format json

4. Опис параметрів CLIУтиліта підтримує такі аргументи командного рядка для режиму analyze:
--log-file — шлях до вхідного текстового файлу логів (за замовчуванням: labs/lab02/data/data_v01/access.log).
--output — шлях для вивантаження фінального звіту (за замовчуванням: labs/lab02/data/data_v01/web_analysis_report.json).
--min-status — мінімальний статус-код помилки для класифікації (за замовчуванням: 400).
--top — кількість IP-адрес із найбільшою кількістю помилок для виведення у топ (за замовчуванням: 5).
--format — формат вихідного звіту, доступні варіанти json або csv (за замовчуванням: json).
--start-time — початкова межа для фільтрації запитів за часовим інтервалом у форматі YYYY-MM-DD HH:MM:SS.
--end-time — кінцева межа для фільтрації запитів.

5. Поведінка при помилкахПрограма побудована з урахуванням обробки винятків та валідації вхідних даних:   Відсутність вхідного файлу: Якщо користувач вказує неправильний шлях до файлу (наприклад, missing.log), програма перехоплює виняток FileNotFoundError/OSError та безпечно завершує роботу, виводячи в потік помилок [ERROR] Файл логу не знайдено.   Некоректний формат дати: Якщо значення для --start-time або --end-time введено неправильно (наприклад, 27.09.2026), кастомний валідатор argparse відхиляє його через ArgumentTypeError та підказує правильний формат YYYY-MM-DD HH:MM:SS.   Недопустимий вибір формату: При спробі передати непідтримуваний формат звіту (наприклад, --format xml), парсер автоматично блокує запит і виводить підказку з доступними опціями (json, csv).   Некоректні статус-коди: Якщо вказано статус-код поза межами 100-599, парсер блокує виконання та просить ввести коректне значення.
